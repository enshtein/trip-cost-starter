# Контекст проекта

## Назначение

Система ведёт рейсы сборных грузов. В одном рейсе могут участвовать грузы
нескольких клиентов. Компания распределяет стоимость рейса между клиентами,
а бухгалтер раз в месяц формирует, проверяет и отправляет им счета, после чего
выгружает отправленные счета в 1С.

## Текущее бизнес-правило и цель изменений

- Сейчас стоимость рейса распределяется пропорционально **весу** груза.
- Новое требование финансовой службы: распределять её пропорционально
  **объёму** груза (`cargo.volume_m3`).
- Это необходимо для справедливого учёта лёгких, но объёмных грузов, например
  чипсов, хлеба и упаковки.
- При изменениях сохраняйте денежные суммы с точностью до двух знаков и
  учитывайте нулевой или отсутствующий объём, чтобы не допустить деления на
  ноль.

## Стек и запуск

- PHP 8.2+ без фреймворка, SQLite через `pdo_sqlite`, jQuery на клиенте.
- Создание или сброс локальной БД: `php bin/reset-db.php`.
- Запуск приложения: `php -S localhost:8000 -t public`.
- Локальная БД `data/app.sqlite` создаётся из `data/schema.sql` и
  `data/seed.sql`; она не должна попадать в Git.

## Структура

| Путь | Ответственность |
| --- | --- |
| `data/schema.sql`, `data/seed.sql` | схема SQLite и демонстрационные данные |
| `lib/db.php` | подключение к БД |
| `lib/functions.php` | общие функции, форматирование и шаблон страницы |
| `lib/billing.php` | расчёт долей рейса и формирование месячных счетов |
| `public/` | PHP-страницы, API, CSS и JavaScript |
| `bin/reset-db.php` | пересоздание локальной базы |

## Ключевые сущности и сценарии

- `trips` — рейсы: дата отправления, машина, грузоподъёмность, стоимость и
  статус.
- `cargo` — грузы в рейсе с клиентом, весом (`weight_kg`), объёмом
  (`volume_m3`) и палетами.
- `invoices` и `invoice_lines` — счёт за месяц и строки с начислениями по
  рейсам.
- `calc_share()` в `lib/billing.php` определяет доли клиентов в стоимости
  рейса; `billing_run_period()` создаёт или пересчитывает счета месяца.
- В счета входят рейсы с датой отправления в выбранном месяце, кроме
  `cancelled`. Повторный запуск пересчитывает строки существующего счёта.
- Статусы счетов: `draft` и `sent`; экспорт в 1С предназначен для
  отправленных, ещё не экспортированных счетов.

## Интерфейс

- `public/index.php` — журнал рейсов.
- `public/trip.php?id=` — карточка рейса и доли клиентов.
- `public/invoices.php` — список счетов и запуск формирования за месяц.
- `public/invoice.php?id=` — состав счёта.
- `public/load_report.php` — отчёт по загрузке машин.
- `public/export_1c.php` — выгрузка счетов в 1С.
- `public/api/trips.php` — API рейсов.

## Рабочие договорённости

- Тексты интерфейса, документация и сообщения коммитов — на русском языке.
- Не добавляйте фреймворк или Composer-зависимости без явной необходимости.
- Используйте существующие функции `h()`, `money()`, `num()` для вывода.
- После изменения схемы обновляйте при необходимости тестовые данные и
  проверяйте проект на чистой БД через `php bin/reset-db.php`.
- Не коммитьте IDE-настройки (`.idea/`), `vendor/` и `data/app.sqlite`.
